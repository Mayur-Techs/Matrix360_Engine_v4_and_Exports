# Customer-facing interface reference

The `Matrix360_Marketing_Command_Center_FINAL.zip` delivery is the approved visual and interaction reference for customer-facing Matrix 360 experiences. It is a frontend prototype, not a source of backend behaviour, availability claims, metrics, integrations, or data-classification rules.

## Product system to preserve

- Calm cream/white surfaces, deep navy content, and teal primary actions.
- Manrope-style editorial headings with DM Sans-style operational text.
- Rounded, lightly bordered panels; a pale mint workspace rail; restrained shadows.
- A command-center orientation: clear primary navigation, useful summary metrics, deliberate review states, and human approval for consequential actions.
- Responsive layouts and visible keyboard focus states.

## Truthfulness boundary

Customer-facing interfaces must show real system status. Illustrative numbers, unavailable integrations, drafts, and previews must be labelled accurately. The reference prototype's simulated marketing modules are not introduced into the audience-intelligence console as live features.

## Current alignment

`apps/web/` uses this visual system for the real Matrix 360 audience workspace. Its uploads, job status, results filters, exports, and audit log are backed by the local service; the data engine remains independent of the presentation layer.
